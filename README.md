# Monograph Terminal

Monograph Terminal is a port of the original [Monograph](https://github.com/xocothemes/monograph)
Ghost theme to a blog-based Astro template — text-first, monochrome, and built for essays,
notes, and long-form writing.

**Live preview:** https://monograph.xocoweb.workers.dev/

```bash
npm install
npm run dev
```

Everything is configured from [src/config/customize.ts](./src/config/customize.ts); site settings
are documented in [CUSTOMIZATION.md](./CUSTOMIZATION.md). For the original Ghost version, see the
[upstream repository](https://github.com/xocothemes/monograph).
